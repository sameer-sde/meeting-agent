Let's get your bot
ready for its first meeting.

Five short steps. Only the first two are needed; the rest make it work on its own, even when you're away.

{{ done }} of {{ total }} done

  1. Connect your Vexa account {% if steps.vexa %}Done{% else %}Required{% endif %}

    Vexa runs the bot that joins your calls. It's free to start, and it keeps your meetings in your own account.

    1. Open vexa.ai and sign in with Google. New accounts get free credit (about 6 hours of meetings).
    2. Go to your Account page → Create API Key → choose Bot Key → copy it. It starts with vxa_bot_.
    3. Click Create API Key again → choose Transcription Key → copy it. It starts with vxa_tx_.
    4. Paste both below and save. Each key is shown only once on Vexa, so paste it here right away.

    Keep your keys private: anyone with them can use your Vexa credit. We store them encrypted and never show them again.

  2. Choose who gets the report card {% if steps.email %}Done{% else %}Required{% endif %}

    After each meeting, the report card is emailed here. Add teammates by separating emails with commas.

  3. Get asked before each meeting {% if steps.telegram %}Done{% else %}Recommended{% endif %}

    A few minutes before a scheduled meeting, Telegram asks you one question: are you joining it yourself?

    Yes, I'll joinThe bot stays out.
    No, send the botThe bot joins and sends the report.
    No answerThe bot joins anyway, so nothing is missed.

    The Telegram bot hasn't been added to this app yet. This is a one-time job for whoever runs the app, not for each user:

    1. In Telegram, search @BotFather (blue tick) and press Start.

    4. Add two lines to the app's settings (the .env file on your computer, or the Environment tab on Render):
      TELEGRAM_BOT_TOKEN=the token
      TELEGRAM_BOT_USERNAME=the username, without @
    5. Restart the app and refresh this page. A Connect Telegram button appears here.
